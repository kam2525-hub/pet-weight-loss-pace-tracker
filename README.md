# 愛犬・愛猫のダイエット目標体重逆算シミュレーター

動物病院で痩せるよう指示されたペットの現在体重と目標から、無理のない減量ペースと毎日の食事量を自動算出するツール

## 🌟 主な特徴
- **完全フロントエンド完結**: サーバー不要でブラウザを開くだけで即座に動作。
- **安心・安全**: データはブラウザのローカル環境のみで処理され、外部への通信は行いません。
- **モバイル対応**: スマートフォン・PCのどちらでも直感的に使えるレスポンシブ設計。

## 🚀 使い方
1. リポジトリ内の `index.html` をブラウザで開きます（または GitHub Pages でアクセス: https://kam2525-hub.github.io/pet-weight-loss-pace-tracker/）。
2. 画面の指示に従って操作します。
